# Pizza-Sales-Analysis
End-to-End Business Intelligence Project using MySQL, Power BI and DAX
## 📌 Project Overview

This project analyses pizza sales transactions from **January--December
2015** to uncover sales trends, customer purchasing behaviour, and
product performance. The solution combines **MySQL** for data cleaning
and exploratory data analysis with **Power BI** for interactive
dashboard development.

## 🎯 Business Objectives

-   Measure overall business performance using key KPIs.
-   Identify peak sales periods.
-   Analyse customer purchasing behaviour.
-   Evaluate product performance.
-   Identify top and bottom selling pizzas.
-   Deliver actionable business recommendations.

# 📈 Key Insights

### Business Performance

-   **Total Revenue:** £817.86K
-   **Total Orders:** 21,350
-   **Total Pizzas Sold:** 49,574
-   **Average Order Value:** £38.31
-   **Average Pizzas per Order:** 2.32

### Customer Behaviour

-   Friday recorded the highest number of orders.
-   Afternoon and Evening were the busiest ordering periods.

### Sales Trends

-   July recorded the highest monthly order volume.
-   September and October experienced the lowest demand.

### Product Insights

-   Classic Pizza was the highest-selling category.
-   Large pizzas accounted for **45.89%** of total sales.

### Product Performance

-   **Highest Revenue:** Thai Chicken Pizza
-   **Most Ordered:** Classic Deluxe Pizza
-   **Lowest Performer:** Brie Carre Pizza

# 💡 Business Recommendations

-   Increase staffing during Friday afternoons and evenings.
-   Promote Thai Chicken Pizza and Classic Deluxe Pizza using bundles
    and loyalty offers.
-   Review pricing or menu placement for Brie Carre Pizza.
-   Optimise inventory for Classic and Large pizzas.
-   Introduce seasonal promotions during September and October.
